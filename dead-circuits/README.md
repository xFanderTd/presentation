# DEAD CIRCUITS

Киберпанк-экшен-рогалик по мотивам **Dead Cells**: 2D, пиксель-арт, неон, процедурные уровни,
быстрые бои с телеграфированными атаками, билды из оружия/навыков/имплантов, перманентная смерть.
Чистый браузер: HTML5 Canvas + Web Audio, без библиотек, ассетов и сборки.

**Играть:** откройте `index.html` в браузере (работает прямо с `file://`) или одиночный файл
`dist/dead-circuits-standalone.html`. На телефоне — в горизонтальной ориентации, есть сенсорное управление.

## Забег
| Этап | Локация | Аналог в Dead Cells |
|---|---|---|
| 1 | **Утилизатор** — ржавый завод-тюрьма корпорации | Prisoners' Quarters |
| 2 | Шлюз — безопасная зона: медкапсула, Коллектор, автомат-магазин | проход с Коллекционером |
| 3 | **Неоновые трущобы** — дождь, вывески, рамен-лавки, крыши | Promenade |
| 5 | **Шпиль данных** — вертикальная корпоративная башня, серверные | Ramparts / Clock Tower |
| 7 | **Ядро** — босс «Смотритель», 3 фазы | Concierge / Hand of the King |

Каждый уровень генерируется из seed (виден в правом нижнем углу), путь до выхода всегда проходим.

## Возможности
- **Движение:** бег, прыжок и двойной прыжок, кувырок с неуязвимостью, автозахват уступов, лестницы,
  спрыгивание с платформ (вниз + прыжок), удар о землю (вниз + прыжок в воздухе).
- **Бой:** 29 предметов — 9 видов ближнего боя, 7 дальнего, 2 щита с парированием, 11 навыков
  (гранаты, турель, дрон, голо-двойник, цепная молния…). У каждого оружия своё условие крита.
- **Статусы:** горение, вирус, шок, заморозка. **Качество предметов:** обычное / редкое / легендарное, 21 аффикс.
- **Чипы усиления** (свитки): Жестокость / Тактика / Живучесть — усиливают оружие своего цвета и дают здоровье.
- **Импланты** (мутации) — 15 штук, выбираются у Коллектора. **Чертежи и улучшения** за ядра сохраняются между забегами.
- **Восстановление:** часть полученного урона (оранжевая полоса) возвращается, если быстро ударить в ответ.
- **Враги:** 13 типов с неоновыми силуэтами и жёлтым «!» перед атакой, элитные варианты с добычей.
- **Звук:** 67 синтезированных эффектов и 7 синтвейв-треков, реагирующих на накал боя.

## Управление
| Действие | Клавиатура | Геймпад |
|---|---|---|
| Движение / лестницы | A D W S или стрелки | стик / крестовина |
| Прыжок | Space | A |
| Кувырок | Shift или L | RB |
| Основное оружие | J или ЛКМ | X |
| Второе оружие | K или ПКМ | Y |
| Навыки | Q, E | LT, RT |
| Аптечка | R | LB |
| Взаимодействие | F | B |
| Карта / пауза | M / Esc | Select / Start |

## Разработка
Структура и контракты модулей — в [ARCHITECTURE.md](ARCHITECTURE.md). Все файлы — IIFE, подключаются
обычными `<script>` в `index.html` и пишут в глобальный объект `G`.

```
js/core.js        математика, RNG, пиксельная графика, шрифт 3×5, ввод, камера
js/physics.js     тайловая карта и AABB-физика актёров
js/player.js      игрок: движение, скелетная анимация
js/weapons.js     оружие, навыки, щиты, аффиксы       js/items.js   объекты мира, лут, импланты, мета
js/enemies.js     13 врагов                           js/boss.js    «Смотритель»
js/level.js       генерация уровней и тайлы            js/background.js  параллакс-город
js/hud.js, ui.js, touch.js   интерфейс, меню, сенсорное управление
js/audio.js       синтез звуков и музыки              js/game.js    мир, забег, цикл, рендер
```

Инструменты (нужен Playwright + Chromium):
- `node tools/shot.mjs "play&seed=7" out.png "wait:60|hold:right:40|press:attack1|shot:hit"` — скриншоты и сценарии;
- `node tools/run-test.mjs 11` — прогон всего забега до победы;
- `node tools/build-artifact.mjs` — сборка одиночного HTML в `dist/`;
- `tools/level-viewer.html`, `tools/audio-test.html` — просмотр уровней и стенд звука.

URL-флаги для отладки: `?play&biome=slums&kind=boss&seed=123&god&weapon=railgun&fps&touch`.
